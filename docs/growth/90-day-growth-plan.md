# Mobile AI Agents — 90-Day Growth Plan

**Start:** 2026-11-23  
**End:** 2027-02-20  
**Owner:** Salman Ashraf  
**Tracking issue:** #91  
**Position:** Mobile engineering and evidence-backed QA for AI coding agents.

## North Star

Help mobile engineers build, test, and ship Android, iOS, Flutter, React Native, and KMP apps with AI that proves its work.

The growth loop is:

```text
Useful mobile problem
  -> reproducible skill or workflow
  -> real app result
  -> device and artifact evidence
  -> shareable case study
  -> successful install
  -> community contribution
```

## Guardrails

- Lead with mobile engineering and QA, not a generic catalog of prompts.
- Add backend or frontend capabilities only when they complete a mobile delivery flow.
- Never claim device, file, security, performance, or design verification without evidence.
- Treat keywords as accurate descriptions, not proof of demand or guaranteed ranking.
- Do not equate npm downloads with unique active users.
- Prefer one meaningful release story over many context-free patch announcements.

## Success Metrics

Review weekly:

1. Qualified GitHub unique visitors and sources.
2. README-to-install and install-success rate where measurable.
3. Demo starts and completions.
4. Visitor-to-star conversion.
5. Issue, discussion, and pull-request contributors.
6. Case-study views, watch completion, and referral traffic.
7. Time from install to first proven mobile result.
8. Number of claims backed by reproducible evidence.
