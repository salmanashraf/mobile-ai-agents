Loop Engineering

Choose the loop. Add the platform.

Mobile AI Agents is organized around repeatable engineering loops, then extended with platform-specific expertise. Security and performance are built in before release, not left as cleanup.

PLANNING Core
Idea discovery, PRD, roadmap, task breakdown, and MVP scope.
ARCHITECTURE Core
System design, module boundaries, model separation, clean code, and maintainability gates.
DEVELOPMENT Core
Feature implementation, UI build, refactor, code review, and one-task-at-a-time delivery.
PERFORMANCE Built In
Startup, ANR, memory leaks, frame drops, battery, network, app size, and regression checks.
SECURITY Built In
OWASP, secrets, auth, storage, deep links, WebViews, permissions, logs, and release hardening.
TESTING Core
Unit tests, UI tests, accessibility, PRD verification, screenshots, and device QA proof.
RELEASE Core
CI/CD, signing, store checklist, release notes, staged rollout, and launch readiness.
GROWTH Core
ASO, store listing, screenshot captions, monetization, and conversion-focused launch copy.
MAINTENANCE Core
Crash triage, context memory, issue-to-agent planning, monitoring, and regression prevention.

Agents

Specialists who never sleep.

Each agent has a name, a personality, and a single clear mission. Drop any agent into Claude Code, Cursor, or Windsurf and it works immediately.

AXIOM Android
Reviews Kotlin/Compose for Clean Architecture violations, coroutine leaks, and anti-patterns.
"Zero tolerance for GlobalScope. Has survived 3 Jetpack migrations."
NAVIGATOR Android
Generates and reviews type-safe Compose navigation, nested graphs, deep links, and bottom navigation.
"Every destination has a type and every pop has a reason."
RETAINER Android
Analyzes LeakCanary traces and heap-retention reports into exact owners, lifecycle fixes, and verification steps.
"Follows every strong reference until the guilty owner confesses."
FREEZE Android
Investigates ANR traces, Play Console clusters, and thread dumps into root causes and production fixes.
"Every freeze has a blocking chain."
SWIFT iOS
Reviews Swift/SwiftUI for retain cycles, force unwraps, MainActor misuse, and async/await correctness.
"Will shame your retain cycles in iambic pentameter if necessary."
DART Flutter
Reviews Flutter for widget rebuild inefficiency, missing const, and state management misuse.
"Counts rebuilds like a miser counts coins."
BRIDGE React Native
Finds bridge call bottlenecks, re-renders, and New Architecture migration paths.
"Tracks every bridge crossing like a border guard."
FORGE Unity
Reviews C# for GC pressure, Update() loop abuse, and draw call inefficiency.
"Frame budget is sacred."
UNREAL Unreal
Blueprint optimization, C++ migration, Tick() abuse, and GC safety.
"Will rewrite your Blueprint in C++ while explaining exactly why."
CRASHER All Platforms
Parses any mobile crash log → root cause → concrete fix → regression test.
"Has a wall covered in stacktraces and string."
SENTINEL All Platforms
OWASP Mobile Top 10 security audit with concrete exploitation paths, not theoretical risks.
"Assumes every input is malicious until proven otherwise."
LAUNCHPAD All Platforms
Play Store + App Store ASO-optimized listing copy, keyword strategy, screenshot brief.
"Knows every keyword algorithm."
PIPELINE All Platforms
Generates complete GitHub Actions / Bitrise / Fastlane configs from project context.
"If it's done manually twice, it's a pipeline waiting to exist."
PERF All Platforms
Profiles slow screens, identifies frame budget bottlenecks, produces concrete optimization plans.
"Carries a stopwatch everywhere."
SCRIBE All Platforms
Converts git commit logs into polished, user-facing release notes for stores and stakeholders.
"Translates git commits into things humans actually understand."
FIGMA All Platforms
Translates Figma specs into production-ready Compose, SwiftUI, Flutter, or React Native code.
"Pixel-perfect or it didn't happen."

Workflows

16 end-to-end processes.

The differentiator. No other mobile AI toolkit has these — full sequences that chain agents and skills from ticket to store.

feature-ship
Ticket → /grill-mobile → /feature-slice → implement → review → tests → PR description
crash-to-fix
Crash alert → CRASHER → fix → regression test → deploy (OTA if available)
app-launch
Release build → SENTINEL → PERF → LAUNCHPAD → SCRIBE → /release-prep → store submission
new-screen
Figma spec → FIGMA → implement → /compose-review → PERF → shipped
ci-setup
PIPELINE generates GitHub Actions / Bitrise / Fastlane → secrets → running on first PR
release-cycle
Feature freeze → CRASHER → SENTINEL → SCRIBE → /release-prep → staged rollout
perf-sprint
Baseline → /perf-audit screen by screen → fix → re-measure → before/after documented
game-level
Design doc → FORGE/UNREAL → /shader-gen → /game-perf → /unity-tdd → playtest-ready
new-project-setup
/grill-mobile → architecture → CI from day one → SENTINEL baseline → test infrastructure
mobile-flight-recorder

issue-to-agent
GitHub issue → classify → route to agents/skills → implementation and verification plan
device-proof-report
Mobile MCP evidence → screenshots, assertions, bugs, and pass/fail proof
mobile-karpathy.md

4 rules that stop AI agents
shipping broken mobile apps.

Add to your project's CLAUDE.md. Share independently. Read the full file →

Rule 1
Ask the API level before assuming
Never assume minimum SDK or OS version. Always ask minSdkVersion or iOS deployment target before writing any platform API call.
Rule 2
Check for existing platform components first
Before generating a custom component, check whether a native or framework equivalent exists. Building custom when standard exists is always wrong.
Rule 3
Never touch what wasn't asked
Mobile codebases are deeply interconnected. State the blast radius before touching anything. Change only the specific file or function asked about.
Rule 4
Performance is a feature, not an afterthought
Ask: "Will this run at 60fps on a mid-range device from 3 years ago?" Never generate synchronous main-thread work or unbounded lists.
Install

One command. All platforms.

Works with Claude Code, Cursor, and Windsurf.

# Install everything for Claude Code (runs from GitHub, no npm needed)
npx mobile-ai-agents install

# Install by platform
npx mobile-ai-agents install --platform android
npx mobile-ai-agents install --platform ios
npx mobile-ai-agents install --platform flutter

# Install a single agent or skill
npx mobile-ai-agents add agent crasher
npx mobile-ai-agents add skill grill-mobile
# Clone and install
git clone https://github.com/salmanashraf/mobile-agency
cd mobile-agency
./install.sh

# Platform-specific
./install.sh --platform android
./install.sh --platform ios
# Android agents: AXIOM, RETAINER, FREEZE + cross-platform team
# Android skills: 5 android + cross-platform skills
npx mobile-ai-agents install --platform android

# Or just one Android agent
npx mobile-ai-agents add agent axiom
npx mobile-ai-agents add agent anr-investigation
npx mobile-ai-agents add agent memory-leak-analyzer

# Prepare Android device QA with Mobile MCP
npx mobile-ai-agents doctor --platform android
npx mobile-ai-agents mcp setup --client claude
npx mobile-ai-agents mcp config init --app-id com.example.app

Read the Android Device QA Setup guide →
# Install for Cursor (.cursorrules in current project)
npx mobile-ai-agents install --tool cursor

# Or for Windsurf
npx mobile-ai-agents install --tool windsurf

# Both tools, all platforms
npx mobile-ai-agents install --tool all
